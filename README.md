# 딸깍공방

우리 집에서 만든 배움 앱 세 개(바둑 첫걸음, 여섯줄, 명화 산책)를 한 주소에서 고르는 시작 페이지와 가족 사용 점검표입니다.

- 주소: https://irun20000-eng.github.io/ddalkkak-gongbang/
- 점검표: https://irun20000-eng.github.io/ddalkkak-gongbang/checklist.html (`#baduk`, `#art`, `#guitar`로 바로 열기)
- 검색에 잡히지 않게 `noindex`를 넣었습니다. 점검표 답은 기기 안(localStorage)에만 저장하고 어디로도 보내지 않습니다.
- 앱을 새로 만들면 `index.html`의 앱 목록에 카드 하나를 더하고 `icons/`에 192px 아이콘을 넣습니다.
- 점검 질문은 `checklist.js`의 `FORMS`에서 고칩니다.
- 시험: `node --test`
